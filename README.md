# Haunted-House-On-The-Hill
A Horror RPG made in NetBeans Java
This RPG follows the protagonist as they happen upon a strange mansion in the woods after their car broke down.
Install and run through Java NetBeans
To use the game simply run the java file in NetBeans and press start when the title screen appears.
After this you should be prompted to select your class and character and then be thrust into the game.
The game will show text after which you will be prompted with a question which you must answer by typing your choice.
When a battle happens the battle screen will pop up.
In the battle screen players will have the option to fight, use an item, or specials.
After the fight the player may level up.
But be warned if you lose a battle you will have to begin the game from the beginning and restart your game.
